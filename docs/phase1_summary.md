# BioMDT Phase 1 总结

## Problem

给定癌症背景、具体变异及单一候选药物，BioMDT 要判断哪些响应结论受到现有证据支持，以及这些结论在哪些条件下成立。课程 PDF 的 20 页均已阅读，采用第 2 页规定的五环节与第 6 页的模拟 MDT 主题。BRAF V600E–vemurafenib 在分子靶点相同的黑色素瘤、结直肠癌和甲状腺癌研究中呈现不同的临床活性及模型反馈，说明仅有「突变→靶点→药物」的路径难以界定跨癌种外推。研究对象是异构证据整合。

## Data

- **CIViC** 冻结 2026 年 11 月月度快照。严格字段筛选后有 500 条证据、418 个疾病–变异–药物键，其中 411 个键仅有一个支持标签。按已支持标签计为 Sensitivity/Response 254、Resistance 156、Reduced Sensitivity 1。还有 10 个粗粒度键存在多支持标签或同标签的相反证据方向，需要按实际条件与研究来源复核。这个规模支持后续审查选取主任务病例，临床高等级子集、比较性标签和正式交叉配对的规模更小。
- **跨背景配对** 按字段产生两组不同标签候选。PIK3CA E542K–PI-103 的两株细胞在源表有药敏读数差异，但独立来源记录为 E545K。另一组 PIK3CA E545K–PI-103 的研究终点不一致。严格可比的异标签对为 0。另有 BRAF V600E–dabrafenib 同研究内的跨癌种相对响应材料，可用于定性解释。
- **证据来源** 完成 UniProt、Reactome、ChEMBL、PubMed 四类接口实测，并保存可重放的快照。CIViC-Fact 适合独立证据核验和检索评价，跨表 ID 链接只用于经核对的子集。
- **GDSC** 连接两版药敏表、组织类型和精确突变，共读取 575,197 条拟合记录。已核查的 GDSC 8.5 无 vemurafenib 条目。BRAF V600E–dabrafenib 和 PIK3CA H1047R–GNE-317 有同药、同变异、同浓度范围的跨癌种细胞系对照。 [数据与接口](03_data_feasibility.md)

## Model

正式候选是 **MedRAG、MedAgents、MDAgents**，覆盖医学 RAG、专家共识和复杂度自适应协作；加 Direct LLM。MedAgentBoard 的入口可复用，论文忠实的 MedAgents 需保留其独立问题及选项专家分支。EvoMDT 原仓库公开访问受限，DrugAgent 的核心输出是药靶预测；二者提供研究参照。 [论文分析](01_related_work.md) · [固定版本和适配](02_baseline_selection.md)

BioMDT 以带来源、极性和条件的证据声明为共享图状态，既有事实和证据缺口决定后续查询与协同。融合阶段对齐组织、变异、模型、治疗历史及终点，区分真正的矛盾、外推条件差异和仍需补证的情况。LLM 提取与综合，程序执行实体归一、缺口调度、引用检查、研究去重和预算。 [方法定义](04_method_definition.md)

当前会话完成研究阅读和案例证据综合。机器上可通过已登录 ChatGPT 的 `~/.local/bin/codex`（0.157.1）在新非交互会话执行 `codex exec --json`，一次纯文本试调返回并完成 `BIOMDT_OK`。PATH 上的 npm 启动器缺少 darwin-arm64 可选二进制，单独固定实测可执行路径。该客户端产生模型元数据回退提示，正式实验应验证版本与具体模型可固定。Python 可以通过 subprocess 启动新的 CLI 调用并解析 JSONL，也可使用官方 SDK 作为后续服务边界。该能力与桌面工作会话的上下文相互独立。 [CLI 试调记录](../results/pilot/codex_cli_smoke.json) · [官方非交互模式](https://developers.openai.com/codex/noninteractive) · [官方 SDK](https://developers.openai.com/codex/sdk)

## Benchmark

主任务对可核验的敏感与耐药病例比较准确率与宏 F1。Reduced Sensitivity 在当前快照只保留为比较对象明确的定性案例。证据精确率和召回率评价引用支持与关键证据覆盖，机制完整度在有人工路径参考的子集上计算，冲突消解率根据预先审核的冲突材料评价。严格 Pair Accuracy 暂无计分样本。GDSC 独立评价预先定义的体外方向与匹配实验的吻合程度。固定同一模型、证据快照与预算，明确原论文及其适配入口，并通过去图、固定调度和去条件匹配的对照定位收益。 [任务与判分](05_benchmark_design.md)

下一阶段按顺序定稿临床/临床前病例、去重和证据可见性，冻结开发与测试证据包，接通一个统一模型调用适配器，实现原论文基线与项目共享图的最小闭环，先到开发集验收各方法的输入输出和预算日志。之后补机制/冲突人工参考并确定能否评估严格配对。

## Biological interpretation

五个真实案例的证据图将数据库中的蛋白功能、信号通路、作用靶点与论文中的癌症条件连接起来。在 CRC 模型，BRAF 抑制后 EGFR 相关反馈能重新激活 ERK；在甲状腺模型观察到 HER3/NRG1 相关反馈，同时符合特定甲状腺癌患者队列可出现部分响应。PI-103 案例显示，即使药理和细胞读数均有出处，等位基因身份不一致也会改变可支持的结论。试点文件保留原始证据、条件、事实与推断边，以及独立的 CIViC 参考文件。 [案例与证据图](../results/pilot/README.md)
