# Benchmark 与评价设计

主任务是根据病例中的癌症背景、具体变异、单一候选药物和可公开提供的非结果条件，推断受支持的响应标签，通过来源给出分子机制与适用范围。临床、病例报告、临床前预先分层。证据图与动态协作的贡献通过同库同模型比较和消融检验。

## 数据单位与切分

- CIViC 筛选结果是候选。正式金标以人工确认的病例及其可适用条目为单位，条件明确的重复来源合并，比较基准不明的 Reduced Sensitivity 和同情境未解决冲突单列。标注者核对 PMID/试验、疾病及治疗阶段、变异与单药、原比较和终点。本快照仅有 1 个 Reduced Sensitivity 候选键，主计分按核准的 Sensitivity/Response 与 Resistance 两类汇报，保留 Reduced Sensitivity 输出并进行比较对象明确的定性核验。
- 两个记录具有同一变异与单药、标签不同或响应条件有差异时进入配对审查。主配对仅保留临床对临床或同协议的临床前对比，终点与治疗历史可比，疾病身份和变异无未解决矛盾。不同组织的提示性跨研究案例可作定性分析；同一器官亚型变化明确标作亚型对。报告独立配对族数量，并按同一变异–药物组归并相关配对。
- 开发/测试按变异–药物组及共享 PMID、试验/队列形成连接组分配。先审核测试可评估集合与标签覆盖，再锁定测试。若连接组过大，缩小任务包或声明无法提供独立子集。试点病例、明确关联的 PMID/试验及衍生条目用于开发。统计重采样以独立组为单位。
- 闭卷 Direct LLM 作为记忆基础对照。证据条件下，主要轨道屏蔽 CIViC 条目、CIViC-Fact 标签、对应标准卷与答案 PMID/试验的精确副本和衍生片段，允许经审查的独立原始证据。目标论文开放的检索核验轨道单独报告，评价找回与引用能力。资料不足时用 `Insufficient evidence`，并逐轨报告可判定分母、答案覆盖率和各标签支持数。基础模型预训练覆盖量未知。
- CIViC-Fact 建独立核验轨道。按其实际开放证据字段构造预设证据池，按原研究标签与提供证据评价；只有标识符、主张粒度、实体和终点均可追溯的一对一链接才用于辅助注释。
- GDSC 建独立体外一致性轨道，筛选同版本、同药 ID、同精确突变且响应可用的细胞系。先冻结样本门槛及病例先验方向，再查看汇总效应。缺药或缺对侧样本时记为不可评估。

## 对照与公平条件

正式候选为 MedRAG（医学检索生成）、MedAgents（医学多专家共识）、MDAgents（复杂度自适应团队协作）。保留原核心流程并统一输入与 JSON 输出，详细改动见 [源码与基线](02_baseline_selection.md)。Direct LLM 作为附加对照。各方法固定同一 model/version、病例、证据库快照、可用工具及索引、生成温度与可比的资源上限；按方法记录模型调用数、检索数、可见证据 tokens、总输入/输出 tokens、时延和超预算/失败。对 MedAgents / MDAgents 的文本协作可给同一固定证据包，相应条件在方法名与报告中标明。共享证据包对照用于隔离融合与推理，动态查询条件用于观察检索策略带来的变化。单独比较等预算与各自默认配置的结果。

| 指标 | 计算与参考数据 | 衡量的能力 |
|---|---|---|
| Accuracy | 金标单标签病例中预测相同标签数 / 病例数，弃答算未命中。补充覆盖率、已回答准确率 | 在同一响应定义下选择正确标签 |
| Macro-F1 | 各有金标支持的类别分别计算 (2TP/(2TP+FP+FN)) 后宏平均。报告每类支持数，弃答计入 FN | 弱势标签识别，避免敏感类别占比掩盖错误 |
| Pair Accuracy | 固定配对集合中两个成员均正确的对数 / 对数；同时报错判同标签比例和按独立组置信区间。无合格对时报告 NA | 保持突变和药物固定时，识别背景相关响应变化 |
| Evidence Precision | 正确支持它所挂接命题且匹配上下文的引用边数 / 提交的唯一引用边数。无引用病例单报并纳入覆盖率。由双人核验或仲裁产生参考 | 验证引用指向原文、关系正确且适用 |
| Evidence Recall | 已覆盖的金标证据单元数 / 冻结可见证据池中已标注的金标证据单元数。用命题、研究及定位作为单元，多条同义证据可满足同一单元 | 找回足以复核支持和反向结论的关键证据 |
| Mechanism Completeness | 每案命中且有适用证据的必需机制单元 / 该案的已审定必需单元数后逐案聚合，允许等价路径。缺机制金标的病例作盲审定性 | 给出从变异到药物及情境差异的可核实链条 |
| Conflict Resolution Rate | 通过独立审核的冲突中，正确判断上下文兼容性与处置方式的数量 / 有仲裁参考的数量。正确保留无法解决也可得分，同时报漏检和假冲突 | 识别真正冲突并避免把条件差异当作冲突 |
| Experimental Concordance | 对预设明确方向的同药同变异 GDSC 跨组对，比较盲推断方向和固定版本中位 LN_IC50 差符号。按全部可评估对汇报、列样本数与不明确方向，必要时仅逐组描述 | 评价临床解释的体外方向是否有外部迹象，分别报告药物和模型环境 |

机制参考通过两人先独立标注实体、路径必要性、适用条件和来源，再仲裁。无法构建完整参考的指标只用于已标注子集并列覆盖，不把未经核验的 LLM 输出作为金标。CIViC 批注支持的响应标签与 GDSC 单药细胞药敏分别报告。

## 分析与消融

固定共享证据、去图结构但保留文本证据，评价可追溯融合。增设单模型读取同一证据包的对照，估计协作本身的收益。固定预算与初始图，把缺口驱动调度换为固定队列，评价每个新增关键证据的成本及有效查询。保留图和调度，移除上下文匹配与冲突处置规则，重点看配对及冲突子集。每种对照同步报告标签准确、证据质量、机制完整和预算；正式评测前先在开发集确定病例纳入及判分规则。
